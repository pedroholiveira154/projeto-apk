Conceitos e Exemplos

Conceitos fundamentais

1. Imagem Docker

É um modelo que contém os arquivos e as instruções necessários para criar um container.

Exemplo:

A imagem Nginx contém o servidor web Nginx, que pode ser utilizado para disponibilizar páginas e aplicações web.

docker pull nginx

Esse comando baixa a imagem Nginx para o computador.

2. Container

É uma instância executável de uma imagem Docker. Nele, uma aplicação pode ser executada de maneira isolada.

Exemplo:

Depois de baixar a imagem Nginx, podemos iniciar um container para disponibilizar uma página web na porta 8080 do computador.

docker run -d -p 8080:80 nginx

Depois, acesse http://localhost:8080 no navegador.

3. Dockerfile

É um arquivo de texto que define instruções para construir uma imagem personalizada.

Exemplo:

Crie um arquivo chamado Dockerfile com:

FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80

Esse arquivo utiliza a imagem Nginx Alpine e copia uma página HTML para o servidor web.

Para construir a imagem, execute:

docker build -t meu-site . 4. Docker Compose

Permite definir e executar aplicações formadas por vários serviços usando um arquivo YAML.

Exemplo:

Um sistema pode utilizar um serviço para o site e outro para o banco de dados.

Com um arquivo compose.yaml configurado:

docker compose up -d

Esse comando inicia os serviços definidos no arquivo.
